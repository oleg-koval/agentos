# AgentOS system guide

Read `AGENTS.md` in the current checkout. On an installed host, read
`/usr/share/agentos/AGENTS.md` before operating the system. It documents the
supported AgentOS commands, Arch package workflow, SSH diagnostics, evidence
boundaries, privacy rules, and actions that require operator authorization.

Use this skill together with `agentos-operator` for ordinary work or
`agentos-maintainer` for authorized maintenance. If the guide is unavailable,
report that fact and use only the smallest read-only checks.
