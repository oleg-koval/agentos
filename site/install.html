Already-provisioned Arch VPS

Supported target: x86_64 Arch Linux with systemd, pacman, an active SSH server, and an existing non-root user. The bootstrap never partitions disks, changes SSH/firewall settings, or reboots.

  1. Download agentos-vps-install.sh and its adjacent checksum from the accepted release.
  2. Run sha256sum -c agentos-vps-install.sh.sha256, then run the script once without --yes to inspect its plan.
  3. Apply with your selected --channel, project roots, and --agents; rerunning is safe.

Trust anchor: EAC73D1D595C8F7D809D42EB268D28C12D93BC1B. The standalone installer embeds the release URL, public key URL, and fingerprint so it does not require a source checkout.

Dedicated physical machine

Use the versioned ISO from the accepted GitHub Release on a disposable VM first, then only on a dedicated approved x86_64 disk. Verify the ISO checksum and detached signature before booting.

Destructive boundary: the physical installer partitions and formats the selected disk after deliberate erase confirmation (Cancel is the interactive default). Back up data and verify the device before continuing.

After installation, keep the Chromium Home fallback and SSH access while validating Native Workspace, updates, reboot health, and staged rollback.

Updates and recovery

Stable updates are signed and scheduled weekly; beta and edge are for supervised validation. Updates do not reboot automatically. Inspect with agentos update --check, apply manually with agentos update --apply, and keep the previous recovery point until health is confirmed.

For a failed physical update, use sudo rollback-workstation list and stage a known boot-safe snapshot. The VPS reset command restores saved repository/configuration files but is not a package rollback.
