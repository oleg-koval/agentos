Community beta · public issue tracker

Bring a useful, redacted report.

Report reproducible problems through the public repository issue tracker. Do not publish hostnames, usernames, IP addresses, paths, tokens, cookies, prompts, or private keys.

Collect locally

On the affected machine, create a local support report and review it before attaching anything. This command writes a report file without uploading it:

agentos support

Also include the output of agentos version, agentos health, and agentos update --check where relevant. These commands do not enable telemetry or upload data.

Issue checklist

  • Expected and actual behavior, with the smallest reproduction.
  • AgentOS version, channel, Arch architecture, and host role (VPS or physical).
  • First meaningful error line and the command that produced it.
  • Whether SSH, the localhost API, Native Workspace, or Chromium fallback is affected.
  • Confirm that the report was reviewed for secrets and private identity.

Evidence boundaries

A source test or CI result does not prove a physical display, keyboard, mouse, reboot, rollback, or friend acceptance. State what was tested and what was not. The maintainer will request live or device evidence only when needed.

Open an issue or read the contribution guide. GitHub sign-in is required to submit issues.
